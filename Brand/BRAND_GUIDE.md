The November materials use a research-note style: white pages, Georgia Bold for full-sentence claims, Helvetica Neue for evidence, hairline tables, one violet accent and native charts with direct labels. No gradients, icon circles, cards, chips or window dots. Arial on this Mac has no rupee glyph, so never use it for text containing ₹. Keynote ignores a hidden axis and drops all labels in a series if one is deleted, so blank small labels with a number format such as `[<1]"";0.0` and set tick labels to none. The app's own screenshots stay untouched. The three background images remain for product and social use, not for investor documents.

The obsolete deck generators have been removed from this working folder because they rebuild earlier claims and pitch terms. The dated cleanup snapshot in Trash retains the original authoring files if they are needed later. Edit current presentations directly using the current content rather than rerunning those old generators.
